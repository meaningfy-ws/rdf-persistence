= RDF Persistence
:description: A toolkit for model-driven applications on RDF triple stores: a library, a code generator and a service kit.

RDF Persistence is a toolkit for building operational applications on RDF triple stores. You model
the domain once, in LinkML; the generator turns the model into Python classes, SHACL shapes, a
JSON-LD context and frames, TypeScript types and an API description; the library stores the
resulting aggregates as RDF in named graphs, with transactions, tenants, files, access control and
events. Your application writes only what is specific to it.
