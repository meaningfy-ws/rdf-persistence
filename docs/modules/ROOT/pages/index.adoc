= RDF Persistence
:description: Developer-friendly persistence, CRUD and transactions over RDF triple stores.

RDF Persistence is a Python library for developer-friendly persistence over triple stores:
model-first object mapping or a LinkML-generated domain with a repository layer, built on
rdflib, Oxigraph and SPARQL 1.1.
