= Feature taxonomy

[IMPORTANT]
.Background, not a commitment
====
This page is part of the state-of-the-art study moved from the rdf-persistence repository (commit `43dc152`). It records options and leanings, not decisions. What rdf-persistence commits to is in xref:architecture/index.adoc[rdf-persistence architecture v1].
====

:description: The single, groomed systematisation of features for RDF persistence / ORM / RAD libraries.

This page is the *one place* where the feature systematisation is kept and groomed.
Every per-library analysis is scored against it; features discovered during analysis are merged
here (new version), then cross-checked across all libraries (see xref:background/soa/method.adoc[Method]).

Version: *v5, final* (2026-11-03, after round 5) — v0 seed (43) + v1 from round 1 (63) + v2 from round 2 (19) + v3 from round 3 (102) + v4 from round 4 (77) + v5 from round 5 (1) = 305 features.
Round 5 confirmed v4 and refined B7 and T7; the taxonomy has converged.
v3 added five areas — AZ authorization (29), G generation (27), T transactions (11), E events (9),
U UI and client (10) — and continued RAD (2), X (6), D (3) and S (5).
v4 adds three areas — B boundaries (16), PG property graph (4), EV evolution (9) — and continues
D (16), G (9), AZ (7), S (4), T (3), U (3), X (2), I (2), E (1) and P (1).
The _First seen in_ column records where a feature was discovered; coverage per
candidate is in the coverage summary below.

== v3 features (merged from round 3)

Round 3 added five angle reports (`angle-authz`, `angle-codegen`, `angle-service`,
`angle-jsclient`, `angle-stores`) and a round-3 section per library. Analysts reused the same
proposed ids, so every proposal was deduplicated by meaning and given a fresh id here; the
<<id-mapping,id mapping>> below traces each original proposal. Proposals that an existing feature
already covers were mapped to it, not added: the stores angle's "effective vs requested changes"
and "subscription rules on deltas" are part of *X12*; the service angle's zero-code service
confirms *RAD1*.
