= Risks and licences
:description: The top ecosystem risks and the licence findings for the recommended components. Not legal advice.

== Licence findings

- The *only licences that can block a product* are BUSL-1.1 (Fluree: customer-defined schemas
  are named in the prohibition) and the commercial stores (GraphDB EE, Stardog). AGPL (Zitadel,
  Mercure) and GPL-2.0 (Virtuoso) are safe *as unmodified separate services* but trigger
  client procurement objections; keep an Apache-licensed alternative for each (Keycloak, plain
  SSE, Fuseki/RDF4J).
- rdf-persistence itself can stay permissive (Apache-2.0 or MIT): all runtime *dependencies* are
  permissive; GPL/LGPL items are services, build-time tools or idea sources.

The full register (licence, governance and bus factor per component) is in the raw report
`openspec/changes/soa-python-rdf-orm/inputs/analysis/angle-integration.md`, Part 2. This is not
legal advice; items marked for a legal check need one before commitment.

*Top five by likelihood × impact:* R2 authorization leak by query shape · R5 references written
as literals · R1 Fluree BUSL for customer-defined schemas · R4 silent loss in the model chain ·
R13 schema evolution without migrations. R16 (lost updates on non-serialising stores) and R6
(the SHACL commit gate) follow closely.
