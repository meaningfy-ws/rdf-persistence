= Getting started
:description: A first walk with rdf-persistence: model one class in LinkML, generate its code, store a note and read it back.

In this tutorial you build the smallest application the toolkit supports: a notes application with
one class, `Note`. You write its model, generate the code, store one note and read it back. It runs
in memory, so you need no triple store, no identity provider and no Docker. It takes about ten
minutes.

The application is in the toolkit's repository, under
`docs/modules/ROOT/examples/getting-started/`, and a test runs it on every change, so what you read
here works with the toolkit on `develop`.

You need Python 3.12 and https://docs.astral.sh/uv/[uv].

== What happened

* `kit.tenancy.create` made a tenant database for the notebook and granted Ada the `owner` role
  on it (`creator_role` in the settings).
* `kit.session(tenant, principal)` opened a session on that database, on Ada's behalf.
* The `Mapper` turned the `Note` into triples, and the `UnitOfWork` sent them in one transaction,
  in the note's own named graph, with a version token.
* `get` read the graph back and the mapper rebuilt the `Note`.
