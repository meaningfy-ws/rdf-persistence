= Use cases
:description: Who uses rdf-persistence and for what: the actors, their goals as use cases, and the capabilities that serve each.

_Who is the toolkit for, and what do they do with it?_

Each use case is one goal of one actor, at the level of a task that is worth doing on its own. It
names the xref:requirements/capabilities.adoc[capabilities] that realise it and the page that
shows how. The requirements behind each capability are in `openspec/specs/`.

== Actors

[cols="1,4",options="header"]
|===
|Actor |Who

|Application developer |Models a domain in LinkML and builds, tests and runs an application with the toolkit: its domain services, composition root and deployment.
|API client |The application's front end, or another system, calling the service the toolkit serves, on behalf of a signed-in person.
|System architect |Designs a system or platform that reuses the toolkit as its data layer, for example an application platform that lets its users build data-centric applications from a model.
|Toolkit developer |Changes rdf-persistence itself: the library, the generator, the metamodel.
|===
