= Capabilities
:description: The capabilities of rdf-persistence, what each covers, and the pages that explain and use it; the requirements themselves are in openspec/specs.
:page-aliases: requirements/index.adoc
:specs: https://github.com/meaningfy-ws/rdf-persistence/blob/develop/openspec/specs

_What does the toolkit commit to, and where is each part documented?_

A capability is one area of behaviour the toolkit commits to. Its requirements, each a SHALL
statement with its scenarios, are the truth of record and live in the repository under
`openspec/specs/<capability>/spec.md`; a change to the toolkit changes them first. This page does
not restate them: it says what each capability covers and where the docs explain it. The
xref:requirements/use-cases.adoc[use cases] say which capabilities serve which goal.
