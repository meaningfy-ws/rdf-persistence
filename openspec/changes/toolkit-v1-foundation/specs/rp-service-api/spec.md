## ADDED Requirements

### Requirement: One generic router serves every aggregate type

The router SHALL serve `/{type}` (list, create) and `/{type}/{id}` (read, replace, delete) for every
aggregate root of the application schema, read at run time, with no generated routes and no
generated Python classes on this path. Bodies SHALL be validated with the generated shapes.

#### Scenario: a new class in the model
- **WHEN** the toy schema gains an aggregate root `Shelf` and the application restarts
- **THEN** `/shelves` serves it with no code added

### Requirement: Plain JSON by default, JSON-LD and Turtle on request

Responses SHALL be plain JSON with `id` holding the IRI and a `Link` header to the generated
context; with `Accept: application/ld+json` or `text/turtle` the same routes SHALL return JSON-LD or
Turtle. Writes SHALL accept JSON and JSON-LD.

#### Scenario: the same book three ways
- **WHEN** a book is read with `Accept` set to `application/json`, `application/ld+json` and
  `text/turtle`
- **THEN** the three responses describe the same triples

### Requirement: Writes are versioned

Every read SHALL return the aggregate's version as `ETag`; every update and delete SHALL require
`If-Match`, answering 428 without it and 409 when it is stale. Errors SHALL be RFC 9457 problem
responses.

#### Scenario: a stale replace
- **WHEN** a book is replaced with `If-Match` holding an old version
- **THEN** the answer is 409 with a problem response and the book is unchanged

### Requirement: Listings are filtered and paged

A listing SHALL accept equality filters on the type's slots, `limit` and `offset`, and one sort key,
and SHALL return a page with `items`, `total`, `limit` and `offset`.

#### Scenario: a page of books
- **WHEN** books are listed with `limit=2&offset=2`
- **THEN** the page holds the third and fourth books and the total count

### Requirement: The contract is published

The service SHALL publish an OpenAPI document generated by a hook over the schema, with LinkML
bookkeeping stripped, and the JSON-LD context at a fixed path.

#### Scenario: the document lists the routes
- **WHEN** the OpenAPI document is fetched
- **THEN** it describes the routes of every aggregate type and their error responses
